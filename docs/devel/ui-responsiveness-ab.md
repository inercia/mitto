## Dominant-cause classification

_Pending._ Each scenario will be classified using the two ratios `perf-ab.mjs`
computes: `webkit/chromium` isolates the **rendering engine**; `wkwebview/webkit`
isolates the **native wrapper** (UIProcess/JIT policy/system integration).
`chromium ≈ webkit ≈ wkwebview` ⇒ **application-dominant**; a large
`webkit/chromium` gap ⇒ **WebKit-dominant**; a large `wkwebview/webkit` gap ⇒
**wrapper-dominant** (WKWebView-specific).
